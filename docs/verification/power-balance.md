# 전력 소모 검토 (2026-11-18)

결론: 터렛 150W, 타워 200W를 유지한다. 현실의 LED 탐조등으로 가능한 출력이며, 게임에서는 넓은 면적을 싸게 밝히는 조명보다 먼 표적을 자동 추적하는 방어 설비에 가깝다. 최적의 밸런스가 실험으로 확정되었다는 뜻은 아니다.

## 현재 설치된 RimWorld 1.7.5011 rev24 기준

Core `Defs/ThingDefs_Buildings/Buildings_Furniture.xml`의 원본 Def를 확인했다. 이번 확인 시 설치본이 기존 개발 대상 1.6.4871에서 1.7.5011로 변경되어 있었다. 아래 표는 현재 설치본에서 직접 확인한 비교이며, 1.6 원본을 이번에 재확인했다는 의미가 아니다. 반경은 Def 수치이며 실제 밝은 셀 수나 동일한 조도를 의미하지 않는다.

| 설비 | 전력 | 광원 반경 / 역할 |
|---|---:|---|
| 스탠딩 램프 | 30W → ColoredLights 연구 후 15W | 반경 12 |
| 벽 조명 | 30W → 연구 후 15W | 반경 11 |
| 투광등 (FloodLight) | 기본값 100W, 연구 적용 50W | 반경 24; 건설 자체에 ColoredLights 필요 |
| 태양등 | 켜진 동안 2,900W | 광원 반경 14, 작물 성장용 고조도; 야간 정지 |
| 탐조등 터렛 | 150W | 최대 60칸 표적 자동 추적, 기본 표적 광원 유효 반경 약 2 |
| 탐조등 타워 | 200W | 같은 조사 성능 + 벽 너머 실외 적 탐지; 지붕 아래 정지 |

탐조등은 ColoredLights 전력 할인 대상이 아니다. 연구 후 투광등 대비 터렛은 3배, 타워는 4배를 소비한다. 고정된 지역의 면적 조명에는 투광등이 훨씬 효율적이고, 탐조등의 가격은 원거리 조사와 자동 추적에 대한 비용으로 해석하는 것이 맞다. 10개를 켜면 각각 1,500W / 2,000W이므로 대량 설치에도 의미 있는 전력 비용이 생긴다.

타워의 추가 50W는 높이 때문에 반드시 필요한 물리적 비용이 아니라 탐지 능력의 게임 밸런스 비용이다. 지붕 제한까지 고려하면 상당히 보수적인 가격이나, 현재 값을 낮춰야 할 확실한 근거는 없다. 같은 밝기라는 이유로 타워가 더 강한 광원을 가진다고 설명하지 않는다.

## 현실 비교

제조사 Green Inova의 [150W/200W LED 탐조등 사양](https://www.greeninova.com/product/150w-high-power-searchlight)은 150W 16,209lm, 200W 21,613lm, 양쪽 모두 빔 각도 3.6°를 제시한다. 현재 모드의 최대 거리 기본 빔 각도 약 3.8°와 비슷한 좁은 빔을 실제로 이 출력에서 만든다. 따라서 150W / 200W 자체가 비현실적으로 크거나 작은 값은 아니다.

다만 이 제조사 사양은 현실성의 사례이지 게임 밝기를 검증하는 측정값은 아니다. 타일을 미터로 고정 환산하거나 게임 조도 0.5를 lux로 환산하지 않는다. 실제 장비의 광학 효율, 모터, 센서와 게임의 단순화된 조명에는 직접적인 대응 관계가 없다.
