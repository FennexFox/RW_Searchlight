# CE night optics probe

Run `Tests/Optics/Run-Optics.ps1` to start an isolated RimWorld 1.6 game with Combat Extended and Searchlight. The probe clears nearby roofs and light sources, places exactly one powered fixed searchlight, sets local time to hour 1, and samples the spot plus cells one to three tiles beyond it along the axis and diagonal. It records RimWorld ground glow, CE `CombatGlowAtFor`, and CE `GetLightingShift` first with an unaided shooter and then with `CE_Apparel_AdvancedNightVision` actually equipped. The script prints the result and retains its temporary profile for log inspection. The observed values are diagnostic and not hard coded as pass criteria.
