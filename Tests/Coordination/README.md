# Coordination scenario fixture

Build the package for the installed game before running the fixture. The runner
selects the RimWorld 1.6 or 1.7 references and executable using `Version.txt`.
For an alternate installation, use the same game directory for both commands.
The checkout must be installed or linked in that game's Mods folder.

```powershell
$game = 'C:\Games\RimWorld'
.\build.ps1 -RimWorldPath $game
.\Tests\Coordination\Run-Coordination.ps1 -RimWorldPath $game
```

The runner uses a fresh temporary save-data profile with Core, Directed
Searchlights, and a harness mod. It prints the profile path and retains the game
logs, result files, and generated save there. It reloads the save in a separate
game process. `-TimeoutSeconds` applies to each process.

The fixture checks the chosen pawn IDs and per-pawn reservation counts. It covers
Spread, Independent, Concentrate, manual collisions, release and power changes,
Sweep arc and 60-cell restrictions, and a second map. It verifies the actual
in-game message and its selectable detection cells, counts emitted sounds, and
asserts the alert batch, marker, absence, and restored cooldown boundaries in
game ticks. A second pawn detected at the same cell while the first message is
live must receive its own marker and opt-in sound while sharing the message.
The fixture also checks that a current save restores the configured policies
and manual target without replaying a detection or restoring its marker.

The 1-, 10-, and 50-lamp scenarios check bounds on candidate snapshot builds and
candidate evaluations over 120 game ticks. Wall-clock time is diagnostic because
it also reflects the game's pacing, rendering, and other simulation work.

The moving-target case follows one walking pawn with ten lamps for 120 ticks
in open terrain. In a 1.6.4871 run, 1,191 mesh poses required 11 obstacle
scans. In a 1.7.5014 run, 1,191 poses required 5 scans. Both runs performed
zero visual strip ray traces. The beam still traces its center to place the
endpoint light. Blockers and map edges retain per-strip clipping.

The `-LegacySave` option runs the separate upgrade check using the ten-lamp
RimWorld 1.6 vanilla runtime fixture generated by the pre-coordination package.
It copies the input save into the temporary profile before loading it.
